# JSON Query Tool — JSONPath 查询工具

一个纯前端、零依赖的 HTML 工具，用于 JSON 数据的查询、格式化与 JSONPath 路径生成。
下载 `json-query-tool.html` 文件，直接在浏览器中打开即可使用，无需安装任何环境。

---

## 功能特性

### 1. JSON 输入与处理

| 按钮 | 功能 |
|------|------|
| 验证 | 检查 JSON 格式是否正确，并在顶部显示结果 |
| 格式化 | 美化 JSON，添加缩进，保持原始 key 顺序 |
| 排序 | 格式化并将所有 key 按字母顺序排序 |
| 压缩 | 去除空白，压缩为单行 JSON |
| 清空 | 清空所有输入与结果 |

- 支持**拖放 `.json` 文件**到输入区，自动读取并验证

---

### 2. 按 Value 查找 JSONPath（正向查询）

在右侧搜索框输入要查找的 **Value**，自动在 JSON 中搜索所有匹配项，并生成对应的 JSONPath 路径。

**智能路径生成逻辑：**

| 场景 | 处理方式 |
|------|----------|
| 值不在数组中 | 直接返回绝对路径，如 `$.store.name` |
| 数组只有 1 个元素 | 使用索引定位，如 `$.store.books[0].title` |
| 数组多个元素 + 可选条件属性 ≥ 2 | 提示使用条件过滤，引导生成条件 JSONPath |
| 数组多个元素 + 可选条件属性不足 | 回退使用索引定位 |

**条件 JSONPath 示例：**
```
$..books[?(@.author=="JK Rowling")].title
```

---

### 3. 树形可视化

点击工具栏的 **🌳 树形** 按钮，在左侧展开 JSON 结构树面板。

- 以树状层级展示 JSON 的所有节点
- 点击 ▶ 展开 / 折叠节点
- 点击任意节点，**自动复制该节点的 JSONPath** 到剪贴板
- 顶部实时显示当前选中节点的完整路径
- 输入 JSON 时实时更新（防抖 500ms）
- 拖放文件时自动打开树形视图

---

### 4. 反向查询（JSONPath → 值）

切换到「**反向查询 (JSONPath)**」Tab，输入已知的 JSONPath 路径，查看其对应的值。

**支持的路径格式：**
```
$.data.name             → 对象属性访问
$.data.items[0].title   → 数组索引访问
$['special key']        → 带特殊字符的 key
```
